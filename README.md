## 🥭 About Me

I'm Jesús Huerta Aguilar, a Computer Science graduate from the Faculty of Computer Science (FCC), Benemérita Universidad Autónoma de Puebla (BUAP). I work in **Business Intelligence** and my next step is to grow as a **Data Analyst**.

I turn raw data into answers. I explore, clean and model data with SQL and Python, and I communicate the findings through dashboards and reports in Power BI and Metabase. I enjoy understanding the business question behind the data, validating its quality, and turning analysis into insights people can act on.

## 📊 Interests

I'm passionate about **Data Analysis, Data Visualization, and Business Intelligence**. My goal is to build a strong career as a Data Analyst by combining technical expertise with business understanding to help organizations make better decisions.

I'm particularly interested in:

- Data Analysis and Exploratory Data Analysis (EDA)
- SQL for analytical querying, data modeling, and ETL processes
- Python (Pandas, NumPy) for data cleaning, analysis, and automation
- Data Visualization, Dashboard Design, and data storytelling
- KPI development and business performance analysis
- Data quality, documentation, and process improvement
- Statistics and Machine Learning fundamentals

## 🚀 Current Focus

Currently, I'm expanding my expertise as a Data Analyst in:

- SQL for analytical querying and optimization (joins, CTEs, window functions)
- Python for data analysis: Pandas, NumPy, EDA, and data cleaning
- Statistics for analysts: descriptive statistics, correlation, and hypothesis testing
- Data visualization and storytelling with Power BI, Plotly, and Matplotlib
- Power BI (DAX, Power Query, Data Modeling) and Metabase as delivery tools for insights
- End-to-end analysis projects: from raw data to a clear recommendation
